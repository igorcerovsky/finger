# Workspace Agent Guidelines

## 1. Git Commit Protocol
- **Do not commit without explicit confirmation:** Never run `git commit` automatically or autonomously.
- **Always ask before committing:** Always present the changes and test results, and ask the user for confirmation prior to creating any commit.

## 2. Scientific Tone & Phrasing
- **Avoid dogmatic or absolute language:** In papers, guides, and docs, avoid words like "must", "never", "mandate", "ban", "mandatory", or "proves".
- **Favor cautious, scientific phrasing:** Use "it is recommended to avoid", "suggests", "indicates", "evidence supports", "is advised", and "is encouraged". Future empirical research may refine or revise findings; maintain scientific humility.
