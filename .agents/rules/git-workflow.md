# Agent Guidelines: Git Workflow & Scientific Caution

## Git Commit Protocol
- **Never commit without explicit user confirmation:** Do NOT run `git commit` autonomously under any circumstances.
- **Always ask for confirmation:** When work is ready to be committed, present a concise summary of the changes, verify that all tests pass, and explicitly ask the user for permission to commit.

## Scientific Phrasing & Caution
- **Avoid dogmatic or absolute language:** In scientific papers, practical guides, and technical documentation, avoid rigid words such as "must", "never", "mandate", "mandatory", "absolute ban", or "proves".
- **Use evidence-informed, cautious language:** Use phrasing such as "it is recommended to avoid", "current evidence suggests", "is advised", "is encouraged", or "literature supports". Remember that sports science and biomechanics evolve with future research; stay cautious, objective, and scientifically humble.
